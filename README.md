# Morocco Temperature Downscaling: A Two-Stage Regression-Kriging Framework

An automated data-engineering and geostatistical pipeline in R that ingests daily maximum temperatures from the European Climate Assessment & Dataset (ECA&D), resolves the coastal environmental lapse-rate paradox, and downscales daily weather anomalies onto a 10-km satellite-derived Digital Elevation Model (DEM) of Morocco using **Two-Stage Regression-Kriging (RK)**.

## Repository Architecture & Pipeline
The pipeline is broken into modular and sequentially executed R scripts located in the `R/` directory:

```text
morocco-geostatistics/
├── data/
│   ├── raw/                 # Original, untouched daily ECA&D text files
│   └── processed/           # Standardized CSVs, downsampled DEM, prediction grid
├── R/                       # Clean R script pipeline 
│   ├── 01_data_prep.R       # Standardizes stations and cleans DMS coordinates
│   ├── 02_eda_spatial.R     # Baseline network maps and microclimate series
│   ├── 03_lapse_rate_mlr.R  # Fits the stable global MLR trend model
│   ├── 04_spatial_anomaly.R # Extracts daily residuals and defines prescribed variogram
│   ├── 05_reg_kriging.R     # Runs the daily Regression-Kriging interpolation
│   └── 06_loocv_validate.R  # Runs cross-validation metrics and error diagnostics
├── output/
│   ├── figures/             # Final high-quality visualization assets
│   └── models/              # Serialized R objects (.rds) for reuse (manually moved from data/processed/)
└── notebooks/
    └── morocco_climatology_study.Rmd  # Narrative-driven HTML report
```

### How to Reproduce
To execute the entire spatial pipeline from scratch, ensure you have the `tidyverse`, `sf`, `gstat`, and `geodata` packages installed, and run the following commands sequentially in your terminal:

```bash
# 1. Ingest, clean, and merge the daily datasets
Rscript R/01_data_prep.R

# 2. Generate baseline maps and climatological time-series
Rscript R/02_eda_spatial.R

# 3. Process the high-res satellite DEM and resolve the lapse rate
Rscript R/03_lapse_rate_mlr.R

# 4. Detrend daily weather and set the prescribed variogram
Rscript R/04_spatial_anomaly.R

# 5. Run the Regression-Kriging interpolation and generate surfaces
Rscript R/05_reg_kriging.R

# 6. Run the cross-validation loop and export diagnostic charts
Rscript R/06_loocv_validate.R
```

## Scientific Deliverables

### 1. Resolving the Topographic Lapse-Rate Paradox
A simple linear regression of temperature vs. altitude across Moroccan stations returns an incorrect **positive lapse rate** due to *maritime confounding* (sea-level coastal stations are heavily cooled by the ocean, while mid-altitude interior plain stations are hot). By fitting a Multiple Linear Regression controlling for **Latitude**, we successfully isolated the true topographic vertical lapse rate of **$-2.13^\circ\text{C}$ per 1,000 meters** of elevation gain:
$$\text{Expected Temp} = 67.37 - 0.00213 \times \text{Altitude} - 1.271 \times \text{Latitude}$$

### 2. Side-by-Side Model Performance
While standard **Ordinary Kriging (OK)** completely ignores physical geography; producing a flat, non-informative temperature sheet, **Regression-Kriging** uses the high-resolution terrain grid as an external drift covariate, resolving localized microclimates while preventing spatial extrapolation collapse ($100+^\circ\text{C}$ outlier errors found during some earlier trials).

### 3. The Cross-Validation Paradox
We conducted a custom **Leave-One-Out Cross-Validation (LOOCV)** loop to evaluate predictive accuracy. On paper, Ordinary Kriging shows a slightly lower RMSE than Regression-Kriging ($5.97^\circ\text{C}$ vs. $6.51^\circ\text{C}$). 

This in fact demonstrates a good example of **spatial smoothing bias**. During the cross-validation, leaving out **Oujda** (which was experiencing an isolated $41.0^\circ\text{C}$ desert heatwave far from the western station cluster) heavily penalizes the trend-anchored RK model. OK achieves a lower error on paper by simply smoothing raw values, though its resulting map is physically useless.
